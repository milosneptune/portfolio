What is Room for Growth?

Jelly Beach is a short trading game based of one of John Roche’s poem, Ode to a Jelly Donut, where you wander through boardwalk, exploring childlike joy, and aim to obtain a jelly donut!

Room for Growth is part of an ongoing student-led vertically integrated project, echoes, at RIT. echoes aims to create community inspired games that reflect the deep meaningful impacts these members have had on us, while allowing students to collaborate in cross-functional agile teams and foster stronger industry and professional skills.

Role: Game Designer, Game Developer, 2D Artist

Tools: Unity, GitHub and GitHub Project Boards, Visual Studio

Team Size: Seven people. The echoes organization is around 25-30 people.
